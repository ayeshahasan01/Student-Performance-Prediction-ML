# Student Performance Prediction using Machine Learning

## Overview
This project predicts whether a student will pass or fail using a supervised machine learning algorithm.

## Algorithm Used
- Logistic Regression

## Features Used
- Study Hours
- Attendance Percentage
- Previous Marks

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn

## How to Run
```bash
pip install pandas numpy scikit-learn
python student_performance.py
